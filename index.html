How this works.

// 01 · Read the module

Each module gives concise concept notes, objectives, and topics — what it is, why it matters, where it shows up in production today.

// 02 · Open the lab guide

Click any lab to open a full walkthrough: topology, numbered steps with real IOS commands, verification, success criteria, and a stretch challenge.

// 03 · Build & document

Build it in Packet Tracer 9, mark it done, and capture it in a GitHub repo. By the end you have 47 documented builds.

v1.1

Current for 2026 — built to age well

Aligned to the CCNA 200-301 v1.1 blueprint (Feb 2026 content refresh, valid through 2027+). v1.1 additions are baked in where they fit: Rapid PVST+ in STP, WPA3 as the default wireless security, and cloud / automation context in the design and capstone modules. The fundamentals — switching, routing, VLANs, subnetting, IPv6, FHRP — are stable knowledge.

Before you start

[✓]Install Cisco Packet Tracer 9.0+ (free with NetAcad; Windows / macOS 10.14+ / Ubuntu 20.04+)
[✓]Install VirtualBox 7+ with a Windows 10/11 client VM
[✓]A note system (Obsidian, Notion, or markdown in a repo)
[✓]A GitHub account for portfolio documentation
[✓]Optional: free NetAcad enrollment for assessments + CCST/CCNA paths
[✓]4–8 hours per week, sustained for ~5–6 months
