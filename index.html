How this works.

// 01 · Read the module

Each module gives concise concept notes, objectives, and topics — what it is, why it matters, where it shows up in production today.

// 02 · Open the lab guide

Click any lab to open a full walkthrough: topology, numbered steps with real IOS commands, verification, success criteria, and a stretch challenge.

// 03 · Build & document

Build it in Packet Tracer 9, mark it done, and capture it in a GitHub repo. By the end you have 69 documented builds.
